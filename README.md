## Introduction

#  FABRIQUE À PROJETS

###  De l'idée à la réalisation !

Bienvenue sur le repository officiel de notre Fabrique à Projets.

Un espace collaboratif dédié à la créativité, à l'innovation et à la concrétisation de projets.

## Description

##  Présentation du projet

La Fabrique à Projets est une démarche collaborative qui permet de faire émerger des idées, de les structurer et de les transformer en projets concrets.

Ce repository permet de centraliser les différents éléments liés au projet, de faciliter le travail en équipe et de suivre son évolution.
## Features

- Light/dark mode toggle
- Live previews
- Fullscreen mode
- Cross platform

##  Nos objectifs

- Stimuler la créativité et l'innovation.
-  Encourager le travail collaboratif.
- Transformer les idées en projets réalisables.
- Organiser et suivre les différentes étapes.
- Documenter les réalisations et les apprentissages.
- Valoriser les projets développés.

    ##  Installation

Pour récupérer le repository sur votre ordinateur :

**1. Cloner le projet**

```bash
git clone https://github.com/Ingride-Siemanou/Formation-A2-git.git
```

**2. Accéder au dossier**

```bash
cd Formation-A2-git
```

**3. Ouvrir le projet dans VS Code**

```bash
code .
```
